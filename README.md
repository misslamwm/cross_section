# 幾何神廚：一刀截面挑戰

純 HTML + CSS + JavaScript、無後端、無 API Key、沒有外部 CDN 依賴。適合 iPad 及電腦的繁體中文幾何截面遊戲。

## 真正的核心玩法

在立體食材上以手指／滑鼠**劃一刀**，系統按手勢方向、螢幕位置及事先選定的鉛垂朝向建立三維平面，對凸立體三角網格進行半空間裁切，沿同一平面顯示兩部分分離和截面的正視圖。不是 ABCD 問答題。

- 左右劃：水平平面（平行桌面）。
- 上下劃：鉛垂平面；「鉛垂橫截面／縱截面」按鈕控制水平法向朝向，按鍵不是答案提示。
- 斜劃：球體任意方向斜切。
- 滑動中刀光跟手移動，鬆手後才確定一刀；滑得太短不計一刀。
- 操作輔助：可用水平或鉛垂輔助揮刀按鈕，不要求精準手勢。
- 第一關按指定平面切割；第二關要求切出均勻截面；第三關切出指定目標或「拒絕不可能訂單」。
- 每關 5 題、每套 15 題、10 套共 150 個完整題目物件；每套 H=7、V=7、球體斜切=1。
- 每題最多計分一次；三連對加 150 分；兩種模式的排行榜分開。

## 檔案

- `index.html`：遊戲進入點
- `styles.css`：響應式 iPad／電腦布局及木質砧板
- `questions.js`：150 筆資料及 10 套菜單；每題都帶模型、位置、答案、原因等欄位
- `geometry.js`：立體三角網格生成、平面求交、兩半裁切及截面正視座標
- `game.js`：遊戲進度、揮刀、計分、動畫、聲音、本機排行榜、教師答案
- `validate.js`：Node.js 題庫驗證
- `assets/`：預留本機素材（本版本使用程式繪圖和合成音效）

## 本機預覽

直接雙擊 `index.html` 可在多數桌面瀏覽器遊玩。若瀏覽器限制本機檔案，也可使用 Python：

```bash
cd geometry-chef
python -m http.server 8000
```

然後開啟 `http://localhost:8000/`。

## 上載到 GitHub 及 GitHub Pages

1. GitHub 新建公開 repository，例如 `geometry-chef`。
2. 下載 ZIP 並解壓，將 `index.html`、CSS、JS、README 等檔案直接放於 repository 根目錄。不要把整個資料夾再套一層。
3. Commit to `main`。
4. Repository → Settings → Pages → Build and deployment → Deploy from a branch → Branch `main` → Folder `/ (root)` → Save。
5. 網址一般是 `https://你的帳號.github.io/geometry-chef/`（依 repo 而定）。

## iPad 開啟

使用 Safari 開啟 GitHub Pages 網址，建議橫向。手指／觸控筆在木砧板中間的食材上劃。畫布已設 `touch-action: none`，避免手勢引致捲動。旋轉畫面會重新繪製但不重設題目／倒數。

## 修改題庫／時間

題庫在 `questions.js` 的 `QUESTIONS` 陣列，逐題完整列出各欄位。可修改食材名稱、模型（`solidType`）、`placement`、`geometryParameters`、`shownCutPlane`、`acceptedCutPlanes`、`expectedSection`、`targetSection`、`isPossible`、`explanation` 等。數學條件變更後須同步核對切面幾何並執行驗證。

時間在 `game.js` 的 `start()`：`config.mode==='quick'?25:60`。如要修改，注意保持各模式排行榜獨立；目前排行榜 key 以模式名分隔。

## 驗證題庫

需 Node.js 18+：

```bash
node validate.js
```

檢查題庫數量、唯一 ID、食材不重複、每關數量、方向配額、第二關五種截面、第三關不可能題數、幾何網格、平面交點以及資料完整性。

## 已知限制及教學定位

1. **2.5D 三角網格表示法**：凸立體使用離散三角面（三角柱／錐體為精確平面；圓柱／圓錐／球面用多邊形網格近似）。圓形截面在正視圖會近似多邊形圓形。這不是 WebGL 精確曲面模型。
2. 為避免手機手勢精度問題，只支援橫切、鉛垂兩個正交朝向，以及球體的固定斜向。尚不支援連續旋轉任意 3D 法向角度。
3. 對第二關「均勻截面」採用柱軸正交截面的判定；並非所有可能的特殊斜向切法都涵蓋。
4. 水平／鉛垂由桌面世界座標定義，不等於平行於食材底面。手指在螢幕上的二維手勢用於**選定三維平面種類及偏移量**，不是把螢幕路徑直接當三維刀痕。
5. 食材是模具塑形的理想化模型，名稱僅為食物造型，不影響幾何判定。
6. 本機排行榜使用 localStorage，只限同一裝置與瀏覽器，**不是班級跨 iPad 即時排名**。儲存不可用時仍可遊玩，但紀錄不保留。
7. 版本定位是幾何截面練習及形成性評估，不保證一次遊玩已全面掌握課題。
8. 在不同 iPad 型號、Safari 版本、實體觸控筆的兼容性尚需校內實機驗證。

## v1.1 外觀及提示調整

- 食物表面由單一顏色改為依食材名稱及菜單調色的多層光影、材質漸層與細粒紋理，並移除外表三角網格線。

- 操作無障礙替代按鈕保留，改名「按鈕替代：水平／鉛垂下刀」，不是截面答案選項。
- 本版本仍是程式繪製的 2.5D 風格化食材，並非照片級材質／完整 3D；iPad 實機手勢和幀率需測試。
