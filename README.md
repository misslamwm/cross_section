# 幾何廚神大挑戰

《幾何廚神大挑戰》是一款適合香港初中學生的截面學習網頁競賽。學生可在 iPad、觸控筆或電腦上揮刀切割卡通食材，認識水平切割、鉛垂切割與均勻截面。無須登入或連接後端。

## 遊戲內容

- 三關分別是「初級學徒」、「資深副廚」和「米芝蓮主廚」。
- 題庫共有 **33 題**（第一關 13 題、第二關 10 題、第三關 10 題）。每次遊戲會從每關隨機抽取 **5 題**，全場共 **15 題**。
- 題序盡量避免相同或相近截面連續出現，並平衡水平及鉛垂的標準切法。
- 第一關：參考截面圖提示，揮刀正確即可過關；**沒有四選一**。
- 第二關：依照主廚純文字指令「請水平切開 ↔️！」或「請鉛垂切開 ↕️！」揮刀，之後完成四選一。
- 第三關：只顯示「請切出均勻截面！」，自行選擇切法，之後完成四選一。
- 切錯後可重試；食材保持完整，以刀光和結果回饋表示操作。每關之間有過場畫面。

## 競賽計分

- 每題最多 **100 秒**，揮刀與四選一共用同一個倒數。
- 速度分：`round(200 × 剩餘有效秒數 ÷ 100)`；每題最高 200 分。
- 有效切錯一次扣除 **10 秒**，不直接扣分。
- 第二、三關選錯一個四選一選項，從本題速度分扣 **50 分**；重按同一錯選項不再重複扣分。
- 本題實得分：`max(0, 速度分 − 50 × 選錯選項數)`；超時得 0 分。
- 每關 5 題最高 **1,000 分**；三關總分最高 **3,000 分**。結果頁只顯示各關得分及全場總分。
- 關卡過場、食材載入及答題後動畫不計入答題時間。競賽規則亦可在首頁按「競賽規則」查看。

## GitHub Pages 部署

1. 解壓縮 GitHub Pages 發佈 ZIP。
2. 將解壓後**所有檔案及整個 `assets/` 資料夾**上載至 GitHub Repository 根目錄。`index.html` 必須位於根目錄。
3. 到 GitHub **Settings → Pages**，選擇 **Deploy from a branch → main → /(root)**，然後儲存。
4. 部署後在 iPad Safari 或電腦瀏覽器開啟該 Repository 的 GitHub Pages 網址。
5. 更新網站後如仍出現舊畫面，請重新整理或清除頁面快取。

## 本機預覽

可直接開啟 `index.html`。如瀏覽器限制本機資源存取，在本資料夾執行：

```bash
python -m http.server 8000
```

再開啟 `http://localhost:8000`。

## 幾何教學說明

本遊戲的食材均按理想化幾何外形判斷。水果籽、奶油螺旋、年輪、紅豆等內部紋理並不構成新的截面外形。

- 水平切割平面與桌面平行；鉛垂切割平面與桌面垂直。第二、三關要求螢幕上清楚橫向或直向的刀路。
- 均勻截面與所選底面平行，形狀及大小均相同。
- 直立角柱水平切、橫放角柱垂直柱軸切，均可能得到與端面相同的截面；仍須依照每題擺放及模型判定。
- 圓錐通過軸線的鉛垂切面是等腰三角形；直圓錐台通過軸線的鉛垂切面是等腰梯形。
- 中空圓柱的筒壁截面可為圓環；填滿餡料的圓柱則以外輪廓圓形判斷。題目有時以理想化外輪廓作答，並非完整食材的精確材料剖面。
- 本遊戲使用 2D 卡通圖片及理想化手勢判定，不是可任意旋轉、切割的真 3D 模擬。

## 修改遊戲資料

調整食物名稱、指令、截面或擺放，可編輯 `levels.js`；若修改模型或刀法，須同步核對 `rules.js` 和 `stage1-rules.js`。調整計分請使用 `competition.js`；修改遊戲介面請使用 `game.js` 及 `styles.css`。
